Artifacts are the files that AI agents produce during conversations — images, HTML pages, code files, documents, and other outputs. The Artifacts page is a cross-conversation gallery that lets you find, preview, and download the deliverables your agents have produced.

## How Artifacts Are Created

Any tool that returns a `ToolResult` with an `artifacts` list generates downloadable files. The agent doesn't need special instructions — artifact creation is a natural side effect of tool execution.

Common producers:

| Tool | Artifact Type | Example |
|------|--------------|---------|
| `python_exec` | Images, HTML, CSV, JSON | A matplotlib chart saved as PNG |
| `template_render` | HTML | A formatted report |
| Code execution tools | Any file | Generated code, exported data |
| Image generation | Images | AI-generated illustrations |

When a tool produces an artifact, it appears inline in the conversation as a downloadable attachment. Deliverables — the files an answer hands over as final output — are also collected in the Artifacts gallery for cross-conversation browsing; intermediate files stay in their conversation.

## The Gallery

The Artifacts page (`/artifacts`) provides a unified view of the deliverables from all your conversations.

### Filtering

Filter tabs narrow the view (All plus four types):

| Filter | File Types |
|--------|-----------|
| **All** | Everything |
| **Images** | PNG, JPG, GIF, SVG, WebP |
| **HTML** | HTML pages and reports |
| **Code** | Any text file except HTML, plus JSON: source code, Markdown, CSV, plain text, YAML |
| **Files** | Everything else — PDF, archives, binary files |

### Vorschau

Klicken Sie auf ein beliebiges Artefakt, um eine Inline-Vorschau zu öffnen:

- **Bilder** — werden in voller Auflösung angezeigt
- **HTML** — wird in einem isolierten Iframe angezeigt (Skripte isoliert)
- **Code** — syntaxhervorgehoben mit automatischer Spracherkennung
- **Markdown** — wird als formatierter Text angezeigt
- **Sonstiges** — wird als Klartext angezeigt oder als Download-Aufforderung

Verwenden Sie die Pfeiltasten, um zwischen Artefakten zu navigieren. Drücken Sie Escape, um die Vorschau zu schließen.

### Metadaten

Jedes Artefakt zeigt:
- Dateiname und Größe
- Erstellungszeitstempel
- Quellkonversation (klicken Sie, um zur Konversation zurückzukehren, in der es generiert wurde)

## Storage

Artifacts are stored on the server filesystem, one directory per conversation. Each artifact is stored under a random 12-character id plus its original name; download URLs carry the conversation UUID. Files are served directly — no database records for individual artifacts, keeping the storage layer simple and fast.
