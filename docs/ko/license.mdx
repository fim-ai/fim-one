# 빠른 요약

### 허용됨

| 사용 사례 | 세부 사항 |
|---|---|
| **내부 사용** | 조직 및 계열사 내에서 내부 비즈니스 운영을 위해 FIM One을 사용합니다. |
| **수정** | 소스 코드를 수정하고 파생 저작물을 만듭니다. |
| **배포** | 라이선스 사본을 포함하여 소프트웨어를 배포합니다. |
| **앱에 임베딩** | 경쟁 제품이나 호스팅 서비스가 아닌 한, FIM One을 자신의 애플리케이션에 컴포넌트로 사용합니다. |
| **단일 테넌트 배포** | 브랜딩이 유지되고 제3자 액세스가 허용되지 않는 한, 전용 환경에서 단일 고객을 위해 FIM One을 배포합니다. |

### 제한 사항

| 제한 사항 | 세부 정보 |
|---|---|
| **다중 테넌트 SaaS / 호스팅 서비스** | FIM One을 제3자에게 서비스로 제공할 수 없습니다(예: "FIM One-as-a-Service", 관리형 다중 테넌트 플랫폼, 또는 클라우드 서비스로 FIM One 기능에 대한 액세스 재판매). |
| **경쟁 제품** | FIM One을 사용하여 경쟁하는 에이전트 오케스트레이션, 워크플로우 실행 또는 작업 계획 제품을 구축하거나 운영할 수 없습니다. |
| **화이트 라벨링 / 브랜딩 제거** | FIM One 브랜딩, 로고, 저작권 공지 또는 라이선스 공지를 제거, 변경 또는 모호하게 할 수 없습니다. 화이트 라벨링에는 별도의 상용 라이선스가 필요합니다. |
| **라이선스 확인 우회** | 라이선스 확인, 기능 제한 또는 자격 확인을 제거, 비활성화 또는 우회할 수 없습니다. |

## 일반적인 시나리오

<Note>
  라이선스는 FIM One을 **어떻게 배포하는지**를 제한합니다 — **수익을 창출할 수 있는지 여부**가 아닙니다. 유료 및 상용 사용은 괜찮습니다. 상용 라이선스 없이는 세 가지 특정 *형태*만 금지됩니다: **다중 테넌트 호스팅 서비스**, **화이트 라벨링**, 그리고 **경쟁 플랫폼 구축**.
</Note>

| 시나리오 | 허용됨? | 이유 |
|---|---|---|
| 자신의 회사 또는 팀을 위해 FIM One을 내부적으로 실행 | ✅ 예 | 내부 사용 (§2a) |
| FIM One을 구축하는 제품의 엔진으로 포함시키고 판매 — 해당 제품이 에이전트 플랫폼이 아니고 다중 테넌트 SaaS로 제공되지 않는 경우 | ✅ 예 | 임베딩 (§2d), 브랜딩 유지 |
| FIM One 기반 솔루션을 **한 클라이언트**에게 제공 (컨설팅 / 시스템 통합): 전용, 단일 테넌트, FIM One 브랜딩 유지, 해당 클라이언트의 내부 사용 | ✅ 예 | 단일 테넌트 예외 (§3a) |
| 동일한 클라이언트 제공이지만 **클라이언트 브랜드로 화이트 라벨링** (FIM One 브랜딩 제거) | ❌ 아니오 | 상용 라이선스 필요 (§3c) |
| **하나의 배포를 여러 클라이언트에게 재사용**, 또는 모든 다중 테넌트 설정 | ❌ 아니오 | 호스팅 서비스 (§3a) |
| FIM One을 사용하여 다른 에이전트 오케스트레이션, 워크플로우 또는 작업 계획 **플랫폼** 구축 | ❌ 아니오 | 경쟁 제품 (§3b) |
| 다중 테넌트 SaaS / "FIM One-as-a-Service" 운영 | ❌ 아니오 | 호스팅 서비스 (§3a) |

<Warning>
  **클라이언트 또는 컨설팅 업무를 진행 중입니까?** FIM One 기반 솔루션을 단일 클라이언트에게 제공하는 것은 허용되지만, **다음의 모든 조건**을 충족해야 합니다:

  1. 배포가 **해당 클라이언트 전용** (단일 테넌트, 고객 간 공유 또는 재사용 불가);
  2. 제공하는 것이 **비즈니스 애플리케이션**이지, 재사용 가능한 에이전트 오케스트레이션 플랫폼이 아님 (그것은 경쟁 제품이 될 것입니다);
  3. **FIM One 브랜딩, 로고, 공지사항이 보이고 변경되지 않은 상태로 유지됨**.

  가장 흔한 실수는 **화이트 라벨링**입니다 — 클라이언트는 종종 자신의 브랜드로 솔루션을 원합니다. FIM One 브랜딩을 제거하거나 숨기는 순간, [상용 라이선스](mailto:license@fim.ai)가 필요합니다. 다중 테넌트 재사용과 경쟁 플랫폼 구축은 또 다른 두 가지 엄격한 제한입니다.
</Warning>

## 주요 용어

- **호스팅 서비스** — 네트워크를 통해 제3자가 소프트웨어의 기능에 접근할 수 있도록 하는 모든 서비스(SaaS, PaaS, API 서비스, 관리형 배포).
- **경쟁 제품** — FIM One과 실질적으로 유사한 에이전트 오케스트레이션, 에이전트 런타임, 워크플로우 실행 또는 작업 계획 기능을 제공하는 모든 제품.
- **파생 저작물** — 소프트웨어를 기반으로 하거나 소프트웨어에서 파생된 모든 저작물(수정, 확장, 개작 포함).
