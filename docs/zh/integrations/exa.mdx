[Exa](https://exa.ai)在FIM One中作为可选的网络搜索后端提供。启用后，智能体可以访问完整的Exa搜索界面——`auto`（Exa推荐的搜索类型）、`neural`、`fast`、`deep-lite`、`deep`、`deep-reasoning`和`instant`——以及结构化内容检索（高亮、文本、摘要）和丰富的过滤选项（分类、包含/排除域名、日期范围和最大期限窗口）。合理的Exa端默认设置开箱即用，因此您可以获得Exa最佳实践，无需手动调整。

## 为什么在 FIM One 中使用 Exa

- **用于智能体推理的神经搜索** — Exa 的嵌入原生搜索返回语义相关的结果，而不仅仅是关键词匹配。这对于需要对网络内容进行推理的研究智能体至关重要。
- **用于复杂查询的深度推理模式** — 在开放网络上进行单次调用的多跳推理，无需智能体自己编排子查询。
- **内置内容提取** — 高亮、文本和可选摘要随搜索调用一起返回，消除了获取和清理页面内容的第二次往返。
- **严格的域名/时效性控制** — 包括/排除域名列表（最多 1200 个条目）、ISO-8601 日期窗口和 `maxAgeHours` 用于时间敏感的工作流。

## 快速开始

### 1. 获取 Exa API 密钥

在 [exa.ai](https://exa.ai) 注册并从仪表板获取你的 API 密钥。

### 2. 在 FIM One 中启用 Exa

添加到你的 `.env`：

```bash
WEB_SEARCH_PROVIDER=exa
EXA_API_KEY=your_key_here
```

设置两个变量，使 `web_search` 通过 Exa 路由。优先使用显式的 `WEB_SEARCH_PROVIDER=exa`，而不是仅依赖密钥自动检测。

### 3. 从任何智能体中使用它

网络搜索作为内置工具暴露给智能体——无需额外配置。配置好Exa后，启用了`web_search`的智能体会通过Exa路由搜索调用。

## 配置

所有Exa特定的参数都有合理的默认值。可通过环境变量覆盖任何参数：

| 变量 | 默认值 | 描述 |
|---|---|---|
| `EXA_API_KEY` | — | **必需。** 您的Exa API密钥。 |
| `EXA_SEARCH_TYPE` | `auto` | 可选值：`auto`、`neural`、`fast`、`deep-lite`、`deep`、`deep-reasoning`、`instant`。 |
| `EXA_CATEGORY` | — | 可选值：`company`、`research paper`、`news`、`personal site`、`financial report`、`people`。 |
| `EXA_INCLUDE_DOMAINS` | — | 逗号分隔的允许列表（最多1200项）。 |
| `EXA_EXCLUDE_DOMAINS` | — | 逗号分隔的阻止列表（最多1200项）。 |
| `EXA_START_PUBLISHED_DATE` | — | ISO-8601格式，例如`2025-01-01`。 |
| `EXA_END_PUBLISHED_DATE` | — | ISO-8601格式。 |
| `EXA_MAX_AGE_HOURS` | — | 仅返回过去N小时内索引的页面。 |
| `EXA_INCLUDE_HIGHLIGHTS` | `true` | 从结果中提取高亮片段。 |
| `EXA_TEXT_MAX_CHARS` | `800` | 每个结果的文本/片段长度上限。 |
| `EXA_SUMMARY_QUERY` | — | 可选的每个结果自定义摘要提示词。 |

### 代码片段如何组装

FIM One 通过级联遍历 Exa 的内容字段来在每个结果上生成有用的代码片段，无论 API 填充了哪些内容类型：

1. `highlights`（用 ` … ` 连接）— 存在时优先使用
2. `text` — 回退到提取的文章文本，截断至 `EXA_TEXT_MAX_CHARS`
3. `summary` — 当上述两者都为空时使用

这保证了下游智能体始终有非空的代码片段可用于推理，即使对于 Exa 无法提取高亮的结果也是如此。

### 预设：新闻监控

```bash
EXA_SEARCH_TYPE=fast
EXA_CATEGORY=news
EXA_MAX_AGE_HOURS=24
EXA_TEXT_MAX_CHARS=1200
```

### 预设：研究论文检索

```bash
EXA_SEARCH_TYPE=neural
EXA_CATEGORY=research paper
EXA_INCLUDE_HIGHLIGHTS=true
EXA_TEXT_MAX_CHARS=2000
```

### 预设：深度推理智能体

```bash
EXA_SEARCH_TYPE=deep-reasoning
EXA_TEXT_MAX_CHARS=1500
EXA_SUMMARY_QUERY=What is the key finding and its supporting evidence?
```

## 归属

来自FIM One的每个Exa请求都携带`x-exa-integration: fim-one`标头，以便Exa可以在维护者仪表板中将API使用情况归属于此集成。这仅用于集成级别的归属——不涉及最终用户识别或跟踪。

Exa 连接器位于 [`src/fim_one/core/web/search/exa.py`](https://github.com/fim-ai/fim-one/blob/master/src/fim_one/core/web/search/exa.py)，遵循与 Jina、Tavily 和 Brave 相同的 `BaseWebSearch` 协议——切换提供商只需更改一个环境变量。
