## 常见场景

<Note>
  许可证限制的是**部署方式**——而非**是否收费**。付费和商业使用完全可以；只有三种特定的*部署形式*在没有商业许可证的情况下被禁止：**多租户托管服务**、**白标**和**构建竞争平台**。
</Note>

| 场景 | 允许？ | 原因 |
|---|---|---|
| 在公司或团队内部运行 FIM One | ✅ 允许 | 内部使用（§2a） |
| 将 FIM One 作为引擎嵌入到你构建和销售的产品中——该产品本身不是智能体平台，也不作为多租户 SaaS 提供 | ✅ 允许 | 嵌入（§2d），品牌保持不变 |
| 向**一个客户**交付基于 FIM One 的解决方案（咨询/系统集成）：专用、单租户、FIM One 品牌完整，供该客户自己内部使用 | ✅ 允许 | 单租户例外（§3a） |
| 相同的客户交付，但**白标**在客户品牌下（FIM One 品牌已移除） | ❌ 不允许 | 需要商业许可证（§3c） |
| 重用**一个部署为多个客户服务**，或任何多租户设置 | ❌ 不允许 | 托管服务（§3a） |
| 使用 FIM One 构建另一个智能体编排、工作流或任务规划**平台** | ❌ 不允许 | 竞争产品（§3b） |
| 运营多租户 SaaS/"FIM One 即服务" | ❌ 不允许 | 托管服务（§3a） |

<Warning>
  **在做客户或咨询工作？** 向单个客户交付基于 FIM One 的解决方案是允许的——但仅当**以下所有条件**都满足时：

  1. 部署**专用于该一个客户**（单租户，不在客户间共享或重用）；
  2. 你交付的是**业务应用程序**，而非可重用的智能体编排平台（那将是竞争产品）；
  3. **FIM One 品牌、徽标和声明保持可见且未被修改。**

  最常见的误区是**白标**——客户通常希望解决方案以自己的品牌呈现。一旦你移除或隐藏 FIM One 品牌，你就需要[商业许可证](mailto:license@fim.ai)。多租户重用和竞争平台构建是另外两条硬性底线。
</Warning>

## 关键术语

- **托管服务** — 任何允许第三方通过网络访问软件功能的服务（SaaS、PaaS、API 服务、托管部署）。
- **竞争产品** — 任何提供智能体编排、智能体运行时、工作流执行或任务规划功能且与 FIM One 功能基本相似的产品。
- **衍生作品** — 基于或衍生自软件的任何作品，包括修改、扩展和改编。
